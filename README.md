# 山陰コンパス

スマホの方位センサーで使えるコンパスアプリです。**H3ロケット10号機の打ち上げの軌跡を、カメラ映像に重ねて見ることもできます。**

## できること

### コンパス
- 16方位（北北東など）と角度を表示
- 真北への補正（米子周辺の偏角 約8.3°西偏が初期値）

### H3ロケット10号機の軌跡を見る
火星衛星探査機（MMX）を載せた H3ロケット10号機の飛行経路を、スマホのカメラ越しに空へ重ねて表示します。

- 打上げ予定：2026年10月20日 4:41:03（種子島宇宙センター）
- 現在地から見たロケットの方位・高さを計算し、予定の軌跡、いまの位置、SRB分離・フェアリング分離などのイベントを表示
- 打ち上げ前は「ここに現れる」位置を案内。画面の外にあるときは矢印で向きを示す
- 現在地から見える時間帯（見え始め・いちばん高い・見え終わり）を予測
- デモ再生（10倍速）で事前に動作を確認できる
- 方位・高さ・画角のずれを補正できる

軌跡は JAXA「ロケット打上げ計画書」の時刻・高度表と打上げ方位角（90°）をもとに計算しています。地表距離は計画書にないため推定値で、表示には数度の誤差があります。

## インストール（Android）

1. スマホの Chrome で [Releases](../../releases/latest) を開く
2. `sanin-compass.apk` をダウンロードしてタップ
3. 「提供元不明のアプリ」を許可してインストール
4. カメラと位置情報の使用を許可する

## 更新のしかた

`www/` の中を編集して main に push すると、GitHub Actions が APK をビルドし、Releases に新しい版を追加します。打ち上げ日時が変わったときは `www/h3traj.js` の `LAUNCH_ISO` を書き換えてください。
